# 1. 비주얼 스튜디오 프로젝트 속성에서 Debug 모드, Release 모드의 차이
### Debug 모드
* 컴파일된 실행 파일에 코드 추적을 위한 디버깅 정보(심볼)를 포함합니다. 코드 최적화(Optimization)를 수행하지 않아 실행 속도가 느리며, 알고리즘의 논리적 오류를 잡는 개발 단계에서 사용합니다.
### Release 모드
* 디버깅 정보를 제거하고, 실행 속도 향상 및 파일 크기 최소화를 위해 컴파일러가 강력한 코드 최적화(루프 전개, 인라인 확장, SIMD 명령어 활용 등)를 수행합니다. 컴퓨터 비전에서는 방대한 픽셀의 행렬 연산이 빈번하므로 성능 평가나 실무 배포 시 반드시 Release 모드로 빌드해야 합니다.

# 2. 비주얼 스튜디오 프로젝트 속성에서 x86 모드, x64 모드의 차이
### x86 모드
- 32비트 환경으로 빌드합니다. 포인터 크기가 32비트이므로, 프로그램이 사용할 수 있는 최대 메모리 공간이 약 4GB로 제한됩니다.
### x64 모드
- 64비트 환경으로 빌드합니다. 포인터 크기가 64비트가 되어 이론상 방대한 양의 메모리 주소 지정이 가능합니다. 고해상도 영상 데이터나 딥러닝 모델(DNN 모듈)을 다루는 컴퓨터 비전 분야에서는 메모리 부족(Out of Memory) 예방을 위해 x64 모드로 개발하는 것이 표준입니다.

# 3. 빌드 전에 비주얼 스튜디오에서 포함 디렉토리(Include Directories)를 설정하는 이유
### 이유
- C++ 컴파일의 첫 단계인 전처리(Preprocessing) 과정을 위한 설정입니다.
### 설명:
- `#include <opencv2/opencv.hpp>` 구문이 참조하는 헤더 파일(`.hpp`, `.h`)들의 물리적 경로를 전처리기와 컴파일러에게 알려주어, `cv::Mat` 등의 자료 구조나 함수 원형(Prototype)을 정상적으로 찾을 수 있게 합니다.

# 4. 빌드 전에 비주얼 스튜디오에서 라이브러리 디렉토리(Library Directories)를 설정하는 이유
### 이유
- 빌드 후반부의 링킹(Linking) 과정을 위한 설정입니다.
### 설명
- 소스 코드가 기계어 목적 파일(`.obj`)로 컴파일된 후, 링커(Linker)가 외부 라이브러리와 연결할 때 필요한 정적 라이브러리 파일(`.lib`)이 모여 있는 '폴더 경로'를 알려주는 역할을 합니다.

# 5. 빌드 전에 비주얼 스튜디오에서 링커 추가 종속성(Additional Dependencies)을 설정하는 이유
### 이유
- 링커에게 연결할 정확한 타겟 라이브러리 파일명을 지시하기 위함입니다.
### 설명
- 라이브러리 디렉토리가 '폴더 위치'를 알려준다면, 추가 종속성 설정은 그 위치에서 어떤 구체적인 파일(예: `opencv_world452.lib` 등)을 가져다 연결할지 명시하여 링커 오류(LNK2019: 확인할 수 없는 외부 기호)를 방지하는 작업입니다.

# 6. DLL을 사용하기 위해 환경변수 Path에 추가하는 경로 및 이유
### 추가하는 경로
- OpenCV 설치 폴더 내의 동적 링크 라이브러리(`.dll`) 파일들이 위치한 bin 폴더입니다. (예: `C:\opencv\build\x64\vc16\bin`)
### 이유
- DLL 파일은 빌드 시점이 아닌 프로그램이 켜지는 런타임(Runtime) 시점에 메모리로 동적 적재(Load)됩니다. 운영체제는 환경변수에 등록된 경로를 탐색하므로, 이곳에 DLL 경로를 등록해 두면 실행 파일 폴더에 매번 무거운 DLL을 복사하지 않아도 알아서 라이브러리를 찾아 프로그램을 정상 구동할 수 있습니다.

# 7. 자신의 사진을 찍고 사진파일을 화면에 출력하는 프로그램을 작성하시오.

## 실행코드(라인 단위 코드 설명)
```c
// OpenCV의 핵심 모듈 및 클래스(Mat 등) 선언을 포함하여 컴파일러가 인식할 수 있게 합니다.
#include <opencv2/opencv.hpp>

// 콘솔 창에 문자열이나 에러 메시지를 출력하기 위해 C++ 표준 입출력 스트림을 포함합니다.
#include <iostream>

// 'cv::' 접두사 없이 OpenCV의 클래스와 함수를 바로 사용할 수 있도록 이름 공간을 개방합니다.
using namespace cv;

// 'std::' 접두사 없이 C++ 표준 라이브러리의 기능을 바로 사용할 수 있도록 이름 공간을 개방합니다.
using namespace std;

int main()
{
    // 현재 링크된 OpenCV 라이브러리의 버전을 런타임에 콘솔 창에 출력하여 환경 설정을 확인합니다.
    cout << "Hello OpenCV " << CV_VERSION << endl;

    // 영상의 화소(Pixel) 데이터와 메타정보를 메모리에 저장하기 위한 빈 2차원 행렬 객체를 생성합니다.
    Mat img;

    // 디스크의 이미지 파일을 디코딩하여 화소 데이터를 추출하고, 앞서 만든 img 행렬에 할당합니다.
    img = imread("myphoto.jpg");

    // 영상 데이터가 정상적으로 메모리에 적재되지 않았을 때 메모리 참조 오류를 막기 위해 프로그램을 종료하는 예외 처리 구문입니다.
    if (img.empty()) {
        cerr << "Image load failed!" << endl;
        return -1;
    }

    // 렌더링된 영상을 화면에 띄우기 위해 운영체제에 'image'라는 고유 식별자를 가진 GUI 창 생성을 요청합니다.
    namedWindow("image");

    // 메모리에 적재된 img 행렬의 화소 데이터를 앞서 생성한 'image' 창에 시각적으로 렌더링합니다.
    imshow("image", img);

    // 창이 바로 닫히거나 응답 없음 상태가 되지 않도록, 사용자의 키보드 입력이 발생할 때까지 GUI 이벤트 루프를 대기시킵니다.
    waitKey();

    // 프로그램이 오류 없이 성공적으로 실행을 마쳤음을 운영체제에 알리고 메인 함수를 종료합니다.
    return 0;

}
```
