### [실습과제 1] 히스토그램 스트레칭 수식 유도

9페이지에 제시된 두 점 (x1, y1)과 (x2, y2)를 지나는 직선의 방정식은 다음과 같습니다.
y = (y2 - y1) / (x2 - x1) * (x - x1) + y1

이 수식을 히스토그램 스트레칭에 적용하기 위해, 힌트에 주어진 두 점 (G_min, 0)과 (G_max, 255)를 대입합니다. 여기서 x축은 원본 영상의 픽셀 값(입력), y축은 변환된 결과 영상의 픽셀 값(출력)을 나타냅니다.

* x1 = G_min
* y1 = 0
* x2 = G_max
* y2 = 255
* x = src(x, y) (입력 픽셀 값)
* y = dst(x, y) (출력 픽셀 값)

위 값들을 직선의 방정식에 대입하여 전개합니다.

1. dst(x, y) = (255 - 0) / (G_max - G_min) * (src(x, y) - G_min) + 0
2. dst(x, y) = 255 / (G_max - G_min) * (src(x, y) - G_min)

위 식의 곱셈 순서를 정리하면 최종적으로 목표한 수식이 도출됩니다.

**최종 수식:**
dst(x, y) = {src(x, y) - G_min} / {G_max - G_min} * 255

### [실습과제 2] 히스토그램 스트레칭과 평활화의 차이

두 기법 모두 영상의 명암비(Contrast)를 향상시켜 영상을 선명하게 만드는 영상 처리 기법이지만, 화소 값을 변환하는 수학적 접근 방식에서 큰 차이가 있습니다.

**1. 히스토그램 스트레칭 (Histogram Stretching)**
* **변환 방식:** 픽셀 값의 양극단(최소값과 최대값)을 찾아 이를 0과 255로 대응시킨 후, 그 사이의 값들을 비율에 맞게 늘려주는 **선형 변환(Linear Transformation)** 기법입니다.
* **분포 형태 (모양):** 원본 히스토그램의 전체적인 모양(분포 형태)은 변하지 않고 0~255의 넓은 구간으로 팽창(Stretching)만 됩니다. 

**2. 히스토그램 평활화 (Histogram Equalization)**
* **변환 방식:** 영상 내 픽셀 값들의 빈도수를 기반으로 확률을 구하고, 누적 분포 함수(CDF, Cumulative Distribution Function)를 이용하여 픽셀 값을 새로운 밝기 값으로 재할당하는 **비선형 변환(Non-linear Transformation)** 기법입니다.
* **분포 형태 (모양):** 특정 밝기 영역에 편중되어 있던 픽셀들이 전체 밝기 영역에 걸쳐 균일한 확률 빈도로 평탄하게 재분배되므로, 원본 히스토그램의 모양이 완전히 달라집니다. 밝기 분포가 한쪽으로 심하게 치우친 영상의 명암비를 극대화할 때 주로 사용됩니다.
